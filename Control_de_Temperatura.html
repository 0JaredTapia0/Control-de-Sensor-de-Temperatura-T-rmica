Acción Segura y Prevención de Errores (Temporizador de 5 s)

Cuando el sensor alcanza el nivel Crítico / Peligro (80% - 100%), la interfaz activa una cuenta regresiva visible de 5 segundos. Si el operador no reduce la temperatura por debajo del 80%, el sistema ejecuta un apagado automático de seguridad restableciendo el equipo a 25 °C (Normal), evitando daños físicos por sobrecalentamiento.
